    Limitaciones Técnicas

    • El sistema usa almacenamiento local (LocalStorage) cuando no hay conexión a Firestore.
    • Las credenciales de usuario se validan de forma simulada (no hay servidor real).
    • El envío de correos solo funciona si se activa un backend con Firebase Functions.
    • El agendamiento se guarda localmente y no se sincroniza entre dispositivos.
    • Estas limitaciones desaparecen al migrar a un entorno con API REST o Firebase completo.
